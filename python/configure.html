Saves your resolved titles to a GitHub repo so a restart doesn't have to start matching from zero. Fully optional — without it the addon works exactly the same, it just re-matches everything after a restart. Get a token at github.com

How do I get this?
  1. Create a small private repo on GitHub (any name works) — this is where the file with your resolved titles will live.
  2. Go to github.com/settings/tokens/new (the link above), give it any name, check the "repo" permission box, and generate it.
  3. Copy that token and paste it above, together with the repo name in "username/repo-name" format.
